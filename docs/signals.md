# Signals

Signals are research predictions only. They never submit real exchange orders and never automatically create paper positions.

Lifecycle: market data -> opportunity analysis -> research observation -> signal -> optional user selection -> Phase 4 paper position -> actual result -> outcome.

Active duplicate identity uses direction, configuration version, time bucket, entry/target ranges, spread/risk band and opportunity strength. Resolved historical signals do not block materially changed future signals.

Expected loss is the estimated entry-to-invalidation/liquidation boundary, not a guaranteed realized loss. Every signal has an explicit expiration/horizon and expired/invalidated history is preserved.
